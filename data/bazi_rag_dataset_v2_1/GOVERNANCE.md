# 数据治理与使用边界

## 信任等级

- A：程序可验证事实、经核验古籍原文或专家审定规则，可支撑规则结论。
- B：来源明确且经专家审核的解释规则，可在限定流派下支撑结论。
- C：解释问答或来源整理的历史命例，只可辅助解释和案例类比。
- Q：隔离数据，禁止进入生产索引。

## 案例库规则

`benchmark_case_qa` 全量进入生产 RAG，但必须遵守：

1. 单个历史案例不得自动上升为普遍命理规则。
2. 相似出生信息或命盘结构不意味着会发生相同事件。
3. 涉及疾病、死亡、灾劫、违法、投资或婚姻伤害的案例必须保留风险标签。
4. 当前用户的结论应先来自确定性命盘事实和 A/B 级规则，案例只作旁证或表达参考。
5. MingLi-Bench 与 BaziQA 重合题采用单记录、多来源，避免重复召回。

## 低可信和隔离区

`data/low_trust/` 与 `data/quarantine/` 默认不向量化、不参与生产检索。大模型评分可以用于排序或抽检，但不能单独把记录升格为 A/B。
