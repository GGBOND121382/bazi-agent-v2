# 岁运确定性关系修复报告

## 修复的问题

1. **原局时柱关系遗漏**：旧实现把岁运目标柱写入时柱位置，导致目标柱与原局时柱无法比较。现改为带位置的多柱关系引擎，原局四柱全部保留。
2. **重复干支误归属**：旧关系只保存字符，多个柱出现相同地支时无法区分。现保存每个参与柱的稳定位置和完整干支。
3. **天干相克不完整**：新增合同表驱动的木克土、土克水、水克火、火克金、金克木完整方向关系。
4. **伏吟缺失**：完整干支相同确定性标记为严格伏吟；同干、同支另行记录。
5. **反吟与天克地冲缺失**：地支六冲叠加干冲/干克时输出反吟候选；干克叠加支冲时额外输出天克地冲并保存克制方向。
6. **岁运并临缺失**：当前大运与流年完整干支相同，输出独立确定性关系。
7. **岁运层之间没有横向计算**：新增大运—流年—流月—流日两两关系和跨三层三合、三会、三刑计算。
8. **立春前年份错位**：公历 1 月至立春前改用上一流年和上一流年最后一个节气月。
9. **Prompt 边界矛盾**：Prompt 不再一边禁止模型计算、一边要求模型自行识别关系；改为强制读取预计算 `relations` 和 `temporal_interactions`。
10. **页面不可见**：岁运页新增交叉关系卡片，展示关系、参与层级、依据和关注等级。

## 数据结构

每条关系包括：

- `fact_id`
- `type` / `label`
- `participants`
- `participant_positions`
- `natal_positions`
- `temporal_positions`
- `direction`
- `basis`
- `rule_id`
- `attention`
- `requires_interpretation`

`attention` 仅代表结构关注程度，不代表吉凶结果。
