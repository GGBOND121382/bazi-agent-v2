# 神煞与岁运计算审计（v2.2）

## 1. 审计对象

本轮以以下材料交叉核对：

1. 用户提供的问真八字截图：`1999-06-29 12:00`，女命，北京，四柱 `己卯 庚午 壬子 丙午`；
2. 用户命例的原局与十二步大运逐项固定回归；
3. `lunar-python` 的 `Yun / DaYun / LiuNian / LiuYue` 实现；
4. 《三命通会》《渊海子平》《协纪辨方书》及问真神煞资料中可核对的规则；
5. 公开名人命盘页面，仅用于核对四柱、真太阳时和起运结果，不把网页断语作为算法真值。

## 2. 原系统差异的根因

### 2.1 把“原局自身命中”和“外来岁运命中”混成同一种计算

原实现把年支、日支三合局类神煞直接扫描四柱，因此：

- 年支卯会把年柱自身误报为“将星”；
- 日支子会把日柱自身误报为“将星”；
- 日支子还会把午误报为“灾煞”。

问真兼容口径中，原局排盘时年支类规则查月、日、时，日支类规则查年、月、时，通常不在锚点柱自身重复命中；但大运、流年、流月和流日是外来柱，不应作这种自柱排除。

### 2.2 灾煞锚点错误

原实现采用“年支或日支三合局”共同查灾煞。截图采用年支查法：己卯年属于亥卯未局，灾煞为酉。因此：

- 癸酉大运命中灾煞；
- 原局两个午柱不应因日支子而命中灾煞。

### 2.3 学堂、词馆混用了另一套查法

原实现将学堂、词馆写成“年干或日干 → 完整干支”的正学堂、正词馆表，导致庚午月误报词馆，又漏掉：

- 己卯年纳音城头土，土命见申为学堂，因此壬申大运命中学堂；
- 土命见亥为词馆，因此乙亥大运命中词馆。

新版保留规则的口径标签，采用问真截图对应的“年柱纳音长生/临官位”作为一般学堂、词馆，不再静默混用正星干支表。

### 2.4 缺少问真使用的规则

新增：血刃、勾绞煞、元辰、四废日、孤鸾煞、九丑日。它们分别解释截图中此前缺失的：

- 年柱己卯：血刃；
- 月柱、时柱丙午以及壬午岁运：勾绞煞；
- 甲戌大运：元辰；
- 壬子日：四废日、孤鸾煞、九丑日。

这些规则存在流派差异，规则数据中标记了来源和变体，不把它们包装成唯一口径。

### 2.5 岁运计算使用近似值

原实现存在三个确定性错误：

- 起运年龄取整数舍入，丢失年月日时；
- 流月用公历每月 15 日采样，而不是精确“节”交接；
- 当前大运主要按近似整数年龄定位。

新版直接使用 `lunar-python` 的精确运对象。用户命例结果为：

- 顺运；
- 出生后 `2年9月17天0小时` 起运；
- `2002-04-15 12:00:00+08:00` 交运；
- 2026 年处于癸酉大运；
- 2026 流年丙午，小运甲戌；
- 2026 十二流月依次为 `庚寅 辛卯 壬辰 癸巳 甲午 乙未 丙申 丁酉 戊戌 己亥 庚子 辛丑`；
- 寅月从 `2026-02-04 04:02:08+08:00` 立春开始。

## 4. 公开命盘抽查

公开页面对以下四柱给出一致结果：

- 用户日期 `1999-06-29`：己卯年、庚午月、壬子日；11:00–13:00 为丙午时；
- 爱因斯坦 `1879-03-14 11:30`：多个独立页面均给出 `己卯 丁卯 丙申 甲午`，并区分钟表时与真太阳时；
- 乔布斯公开案例常用 `乙未 戊寅 丙辰 戊戌`，也有页面采用乙未时，说明名人时柱资料本身存在分歧。

名人出生时刻、历史时区和不同网站采用的神煞流派可能有争议，因此只作为跨站四柱、纳音、空亡和典型神煞的抽查，不用于定义唯一神煞规则。规则真值仍以可追溯规则表、官方日历库和固定回归样例为准。

## 5. 当前输出字段

大运、流年、流月、流日均返回：

- 干支；
- 天干十神、地支主气十神；
- 藏干及对应十神；
- 长生十二运、自坐；
- 纳音、旬空；
- 神煞及规则 ID、锚点、来源和口径；
- 与原局的天干地支关系。

流月额外返回精确节气起止时间；流年返回年龄和小运；大运返回起止年份、起止年龄；流日支持指定日期查询。
