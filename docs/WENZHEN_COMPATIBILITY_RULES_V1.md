# 问真兼容神煞与关系规则 V1

## 目标

本轮修复只把可确定计算的结构写入规则层，不把神煞、暗合、拱合、争合等标签直接解释成吉凶或灾祸。默认配置为 `wenzhen_compatible_v1`，同时保留 `ziping_conservative_v1` 供代码级对照。

## 资料口径

- 《三命通会》：用于勾绞顺逆、三合成局边界、四库齐全等经典关系依据。
- 《渊海子平》：用于金神三柱口径及其“必须结合制化”的解释边界。
- 用户提供《神煞大全》：用于童子煞、问真金神落柱、九丑日表以及问真页面兼容口径。
- 12 个问真命造截图：仅作为兼容回归样例，不覆盖经典原文，也不用于证明吉凶结论。

## 新增或修正规则

### 神煞

1. 童子煞：按月令季节与年柱纳音两组口诀检查日、时支，结果保留命中依据。
2. 金神：问真兼容口径检查日柱和时柱的 `乙丑、己巳、癸酉`。
3. 勾绞煞：修正阴男样例中命前三辰的命中位，不再错误反转为后三辰。
4. 九丑日：修正为九个问真兼容日柱，避免乙酉被误报。
5. 既有天德合、月德合、飞刃、血刃、流霞等规则继续使用版本化表驱动实现。

### 原局和岁运关系

1. 柱内盖头、截脚。
2. 原局整柱伏吟。
3. 暗合候选，并列出对应藏干五合依据。
4. 拱合候选、拱会候选，并记录缺失中神。
5. 两支刑触发与完整三刑分层。
6. 辰戌丑未齐全的四库土结构候选。
7. 多干争合、妒合候选。
8. 现有天干合冲克、地支合冲刑害破、三合、三会、半合、半会继续保留。

## 结果边界

- `hidden_combination` 只表示暗合候选，不证明已经合化。
- `arching_combination` / `arching_meeting` 只表示缺中神的拱结构。
- `punishment_trigger` 表示三刑组中的两支已经出现，不等同完整三刑。
- `four_tombs_earth_structure` 表示四库齐全，可作为土结构候选，不自动断定吉凶。
- `competing_combination` 表示多个天干争取同一五合对象，是否妒合、合留或合去仍需结合位置、旺衰和喜忌。
- 神煞和扩展关系均带 `variant`、`basis` 或来源信息，LLM 只能解释预计算结果，不得自行补算。

## 规则配置

`contracts/calculation_profile_v1.yaml`：

```yaml
relations:
  rule_profile: wenzhen_compatible_v1
shensha:
  rule_profile: wenzhen_compatible_v1
```

- `wenzhen_compatible_v1`：输出经典基础关系和本轮问真兼容候选。
- `ziping_conservative_v1`：排除标记为问真兼容的扩展候选和兼容神煞，用于基线对照。

配置由 `viewmodel_mapper` 真正传入关系与神煞引擎，不再只是文档元数据。

## Golden tests

测试数据：

- `backend/tests/golden/wenzhen_compatibility_v1.json`
- `backend/tests/golden/test_wenzhen_compatibility_golden.py`

覆盖 12 个命造，其中 8 个按公历时间重新排盘，4 个历史命造按截图四柱验证派生规则。测试同时验证：

- 12 个四柱保持一致；
- 童子、金神、勾绞和九丑修正；
- 盖头、截脚、暗合、拱合/拱会、两支刑、四库、伏吟；
- 保守配置会排除问真兼容扩展。

## 仍保留的差异

1. 起运小时与问真仍可能有约 1–2 小时差异，原因是节气时刻数据和折算舍入口径；大运方向、干支序列、起始年份和年龄不受影响。
2. 德秀贵人等少数神煞存在落柱或查年/日范围的流派差异，暂不为了截图强行覆盖经典表。
3. 问真截图会省略部分基础相克、半合、半会，系统仍完整保留这些确定性结构。
4. 系统不把六合、三合、暗合或拱局自动写成“已经化成”，成化仍交由后续专业分析判断。
