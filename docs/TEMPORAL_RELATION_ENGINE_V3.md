# 岁运交互确定性引擎 V3

## 1. 设计边界

本引擎只输出可以由干支和时间层级直接判定的**结构关系**，不直接判吉凶、疾病、灾祸或现实事件。
旺衰、喜忌、格局、成化条件、冲合救应和现实领域影响仍由解释层结合 RAG 分析。

每条关系均返回：

- 参与干支；
- 参与柱位；
- 作用方向（存在方向时）；
- 确定性规则 ID；
- 组合依据；
- 关注等级；
- `requires_interpretation=true`。

因此，“高关注”表示结构叠加较强，不等于必凶。

## 2. 基础关系

### 天干

- 五合；
- 四组传统天干相冲；
- 完整五行相克方向：木克土、土克水、水克火、火克金、金克木；
- 同干重复。

### 地支

- 六合；
- 三合、半合；
- 三会、半会；
- 六冲；
- 六害；
- 相破；
- 三刑、互刑、自刑；
- 同支重复。

三合、三会和三刑可以跨越原局、大运、流年、流月和流日组合，不再局限于单个四柱对象。

## 3. 复合岁运关系

### 伏吟

采用可审计的严格口径：两个层级的完整干支相同，即同干同支。
系统另行输出同干和同支，避免把“只同干”或“只同支”混写成完整伏吟。

### 反吟候选

当两个完整柱同时满足：

- 地支六冲；
- 天干相冲或存在五行相克；

则输出 `fanyin`，并在 `basis` 中明确是“干冲＋支冲”还是“干克＋支冲”。
由于不同流派对反吟口径存在差异，标签明确写为“反吟候选”，解释层不得把标签本身直接断为凶灾。

### 天克地冲

当两柱同时满足：

- 一方天干五行克制另一方天干；
- 两柱地支六冲；

输出 `heaven_controls_earth_clashes`，并保存克制方向。

### 岁运并临

当前大运与流年完整干支相同，输出 `suiyun_binglin`。该关系同时仍保留一般的伏吟、同干和同支记录，便于审计。

## 4. 柱位与交叉层级

原局柱位使用：

- `natal_year`
- `natal_month`
- `natal_day`
- `natal_hour`

岁运层级使用：

- `dayun`
- `liunian`
- `liuyue`
- `liuri`

引擎保留每一个柱位实例，因此原局存在多个相同地支时，会分别输出对应的年柱、月柱、日柱或时柱关系，不再按字符去重后误归属。

当前上下文确定性计算：

- 每一步大运与原局四柱；
- 流年与原局四柱；
- 每个流月与原局四柱；
- 指定流日与原局四柱；
- 当前大运、流年、选中流月、选中流日之间的两两和三柱组合关系。

## 5. 立春边界

流年不再直接等同于公历年份。对公历 1 月至立春前的日期：

- 流年取上一干支年；
- 流月取上一流年最后一个节气月；
- 当前大运按该实际流年定位；
- 岁运交叉关系使用实际流年和流月计算。

例如公历 2026 年 1 月仍属于乙巳流年，立春后才进入丙午流年。

## 6. LLM 边界

报告和问答 Prompt 必须直接读取：

- 各岁运柱的 `relations`；
- 根上下文的 `temporal_interactions`；
- `interaction_summary`。

模型不得自行补算伏吟、反吟、天克地冲或岁运并临；未出现在确定性上下文中的关系不得凭记忆创造。
模型只解释这些结构在当前旺衰、喜忌、格局、宫位和救应条件下可能意味着什么。
