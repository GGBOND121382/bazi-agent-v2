# 关键设计决定

1. **不自研完整天文历法。** 使用成熟库并双引擎复核；自研只限于明确可验证的规则和 adapter。
2. **不把 CoT 当知识。** 只保留结构化推理摘要和工具轨迹。
3. **不把神煞作为主分析器。** 神煞输出是版本化命中事实。
4. **不自动混合流派。** 不同流派使用不同 rule set 和 corpus filter。
5. **不全量预计算流日。** 按用户查询范围生成。
6. **不在第一阶段微调。** 先积累经过验证的结构化数据，再决定 SFT 或偏好训练。
7. **PostgreSQL + pgvector 优先。** 减少独立基础设施，同时保留全文检索和元数据过滤。
8. **报告生成与分析分离。** 报告模型只能编辑已验证 claim。
