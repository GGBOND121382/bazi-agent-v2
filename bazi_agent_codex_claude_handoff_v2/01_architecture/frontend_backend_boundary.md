# 前后端边界

## 后端唯一负责

- 时间、时区、DST、真太阳时；
- 公历/农历、节气和四柱；
- 藏干、十神、纳音、十二长生、空亡；
- 起运、大运、流年、流月、流日；
- 刑冲合害和神煞；
- RAG、模型分析、验证和报告块；
- 权限、分享 token、审计和 PDF。

## 前端允许负责

- 输入交互和客户端基础格式校验；
- 日期/时间控件与时区确认；
- DTO 到 ViewModel 的显示格式化；
- 排序、筛选、折叠、选中状态和路由；
- 图表布局、响应式和打印样式；
- 异步进度、重试和错误呈现。

## 前端禁止负责

- 根据生日计算干支；
- 根据日主推算十神；
- 计算顺逆排、起运或大运；
- 判断合冲刑害；
- 依据颜色或组件逻辑生成“吉凶”；
- 在后端缺字段时自行补全；
- 直接渲染模型原始 Markdown/HTML。

## 契约变更

任何跨边界字段变更必须：

1. 修改 JSON Schema/OpenAPI；
2. 更新示例与契约测试；
3. 重新生成 TypeScript 类型；
4. 更新 `API_CONTRACT_DIFF.md`；
5. 后端和前端分别通过测试。
