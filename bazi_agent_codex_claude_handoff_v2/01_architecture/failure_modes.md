# 失败模式与处理

| 失败模式 | 检测 | 处理 |
|---|---|---|
| 时区缺失 | 输入校验 | 要求补充；不得默认本地机器时区 |
| DST 不存在时间 | zoneinfo 往返检测 | 拒绝并提示合法时间范围 |
| DST 重复时间 | fold 不明确 | 生成两个候选或要求用户选择 |
| 接近节气 | 距离小于阈值 | 双候选命盘或人工复核 |
| 主复核引擎不同 | 字段 diff | `needs_review`，停止 LLM |
| 第三方库升级改变结果 | golden test | 阻止发布，记录版本差异 |
| 神煞规则冲突 | rule_set 不一致 | 分流派输出，不合并 |
| RAG 引用不存在 | 引用验证 | 删除断言或重试检索 |
| 模型篡改干支/十神 | 事实验证 | 整体拒绝 |
| Prompt 注入 | 输入与证据隔离 | 证据作为数据，不执行其指令 |
| 评测集污染 | 路径和哈希黑名单 | 构建失败 |
| 个人数据泄露 | 日志扫描 | 脱敏、拒绝发布 |
