# 许可证和来源风险审计

## 审计字段

每个来源必须填写：

- 数据集许可证；
- 上游原文或网页来源；
- 作者和发布时间；
- 是否包含现代受版权保护的书籍；
- 是否由模型合成；
- 合成模型和输入资料；
- 是否包含真实人物信息；
- 是否允许商业用途；
- 是否要求署名、同方式共享或保留通知；
- 是否允许进入训练、RAG 或仅评测。

## 决策规则

```text
许可证清晰 + 来源可追溯 + 内容审核通过 → approved
许可证清晰但上游来源不清 → quarantine
合成数据未验证 → quarantine
真实个人敏感事件 → evaluation_only 或 restricted
基准测试 → evaluation_only
许可证不兼容或来源无法解释 → rejected
```

## 不得以数据卡许可证替代上游审计

例如数据集标注 MIT，并不自动意味着从现代网站或书籍复制的全部内容都获得 MIT 授权。开发智能体不得自动把 `declared_license` 解释为“无风险”。
