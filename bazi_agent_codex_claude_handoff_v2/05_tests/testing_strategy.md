- 天干地支表；
- 五行生克；
- 一百种十神组合；
- 藏干；
- 合冲刑害匹配；
- 神煞种子规则；

## 契约测试

- 两个历法 adapter 对同一内部协议；
- LLM provider 输出符合 Schema；
- RAG chunk 具有完整来源；
- 报告生成器不读取未验证 claim。

## Golden 测试

- 固定依赖版本；
- 普通日期；
- 节气前后一秒；
- 00:00 和 23:00；
- 海外 DST；
- 真太阳时跨时辰；
- 闰月；
- 库升级前后 diff。

## 模型评估

- 事实准确率；
- 引用支持率；
- 流派一致率；
- 幻觉率；
- 前后矛盾率；
- 高风险确定性措辞率；
- 结构化输出成功率；
- 成本和延迟。
