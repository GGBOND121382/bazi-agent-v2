# 历法边界测试清单

不要在未人工验证前把下面的 expected pillar 写死。先通过两个引擎生成差异，再选择金标来源。

1. 立春前 1 秒、交接时刻、后 1 秒；
2. 每个“节”前后 1 秒；
3. 22:59:59、23:00:00、23:59:59、00:00:00；
4. 每个两小时边界前后 1 秒；
5. 地方平太阳时修正前后跨时辰；
6. equation-of-time 修正后跨时辰；
7. 美国 DST 春季不存在时间；
8. 美国 DST 秋季重复时间 fold=0/1；
9. 中国历史夏令时年份；
10. 农历闰月；
11. 公历闰日；
12. 依赖库支持范围的最早和最晚日期。

每个测试保存：输入、profile、主引擎、复核引擎、差异、人工判定和来源。
