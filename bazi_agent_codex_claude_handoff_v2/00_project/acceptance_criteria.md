# 总体验收条件 v2

## 计算正确性

- 所有历法和命理事实由确定性代码产生；
- 主、复核引擎差异可见；
- 计算 Profile 完整写入结果；
- 临界时刻生成候选命盘或明确警告；
- 十神、藏干、关系、起运和大运均可单元测试；
- 同一输入、配置和版本得到稳定规范化 JSON。

## 前端产品

- 首页、录入、临界确认、进度、命盘、结构、大运、流年、流月/日、报告、历史和设置均有明确页面；
- 桌面 1280px、平板 768px 和移动 390px 核心流程均可完成；
- 页面支持 loading、empty、partial、error、stale；
- 前端没有十神、干支、起运、关系等业务算法；
- 确定性事实、传统规则和模型点评视觉区分；
- 图表有文本或表格替代；
- 临界命盘选择可撤回并重新计算；
- 不显示模型内部 CoT；
- PDF 与屏幕报告关键内容一致；
- 核心页面 Playwright 截图回归通过。

## RAG 可追溯性

- 每个 chunk 有唯一 ID 和原文哈希；
- 保留来源、许可证、版本、章节、页码/URL；
- 只有 approved 数据可被生产检索；
- evaluation-only 哈希在污染黑名单；
- 报告引用可跳转到证据抽屉。

## 模型可靠性

- 模型不能改变工具事实；
- 所有结论携带 fact_ids、rule_ids、evidence_ids；
- 验证失败不渲染正式报告；
- 报告编辑器不能新增结论；
- 不存储或展示内部自由文本长 CoT。

## API 与异步任务

- API 使用稳定错误码和 request_id；
- 分析任务支持状态查询、SSE、取消和幂等重试；
- SSE 断线后可按 event_id 恢复；
- 前端刷新后能恢复当前任务；
- 任务失败区分可重试与不可重试。

## 隐私与安全

- API key 只在服务端；
- 日志不记录完整出生信息和精确地点；
- 删除操作覆盖命盘、分析、报告、分享 token 和派生缓存；
- 分享默认关闭且支持过期与撤销；
- 报告内容进行 XSS 安全渲染；
- 普通用户无法访问数据治理和模型管理接口。

## 工程质量

- 可重复构建与锁文件；
- 数据库迁移可回滚；
- OpenAPI 与生成类型无未提交 diff；
- 后端/前端严格类型检查；
- 文档包含运行、测试和故障排查；
- 每个里程碑有证据而非口头完成声明。
