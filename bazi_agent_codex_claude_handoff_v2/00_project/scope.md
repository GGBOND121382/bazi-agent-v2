# 项目范围

## 系统组成

1. Web 前端产品；
2. 计算与规则后端；
3. RAG 数据治理和检索；
4. 结构化大模型分析与验证；
5. 报告渲染和 PDF；
6. 历史记录、审计和配置；
7. 自动化测试与评估。

## 输入

- 性别；
- 公历出生日期与时间；
- 出生地点或明确时区；
- 时间精度；
- 是否使用真太阳时等高级设置；
- 分析主题和目标时间范围。

## 输出

- 标准化时间与农历、节气；
- 四柱、藏干、十神、关系和基础派生事实；
- 起运、大运、流年、流月、流日和神煞；
- 可追溯的结构化分析；
- 交互式页面、HTML/JSON 和 PDF 报告。

## 产品边界

命理分析属于传统文化解释框架。系统不得将其包装为科学诊断、医疗建议、投资建议、法律建议或确定性人生预测。
