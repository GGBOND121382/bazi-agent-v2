# 用户故事与验收场景

## 出生信息

- 作为用户，我可以输入性别、公历出生日期、精确时间和出生地，以便系统使用正确时区排盘。
- 当我不知道分钟时，我可以标记时间精度为“时辰/约略/未知”，系统明确降低确定性。
- 当出生时间接近节气、换日或时辰边界时，我能看到差异影响并选择候选命盘。

## 分析过程

- 提交后，我能看到“时间标准化、排盘、起运、检索、分析、验证、报告”真实阶段。
- 某一步失败时，我能知道可否重试、是否需要修改输入，以及已完成的数据是否保留。
- 页面不会展示内部 CoT、API key、调用参数或未审核原文。

## 命盘阅读

- 我能在一屏内看到四柱、藏干、十神、纳音和基础关系。
- 我能切换“简洁/专业”模式；专业模式显示规则 ID 和更多中间事实。
- 所有颜色含义都有图例，关闭颜色后仍可理解。

## 大运和流运

- 我能在年龄和公历年份双轴上查看大运，并快速定位当前时间。
- 点击某步大运后，流年页自动继承上下文。
- 流日不能脱离所属大运、流年、流月单独展示为确定结论。

## 证据和报告

- 我可以展开关键结论，看到 `fact_ids / rule_ids / evidence_ids / counterevidence`。
- 我能区分“程序计算事实”“传统规则解释”“模型综合归纳”。
- 我能导出与屏幕内容一致、适合打印的 PDF。

## 历史与隐私

- 我能给命盘设置匿名备注，而不必保存真实姓名。
- 我能删除命盘及其报告，并收到删除范围说明。
- 分享链接默认关闭；启用时有有效期和撤销入口。
