# 假设、争议点和暂不决定事项

## 默认假设

- 默认流派：`ziping_standard_v1`；
- 年柱以立春精确交接时刻为界；
- 月柱以十二“节”的精确交接时刻为界；
- 默认民用时间，不自动启用真太阳时；
- 默认 00:00 换日；
- 顺逆排采用“性别 + 年干阴阳”；
- 起运以顺行取下一节、逆行取上一节；
- 起运折算采用“三天一岁”；
- 神煞只启用 `core_v1`，且只作为辅助事实。

这些是假设，不是跨流派真理。所有字段都必须可切换并写入结果。

## 必须留作策略接口

- 早子/晚子与 23:00 换日；
- 年柱正月初一、立春当日、立春时刻；
- 月柱节当日、节时刻；
- 真太阳时算法和历史时区；
- 起运参考节或气；
- 起运折算和年月日换算；
- 隐藏干权重；
- 旺衰、格局、调候和用神；
- 神煞集合及取年干、日干、年支、日支的依据。

## 产品层应询问用户的情况

- 出生时间不确定；
- 距节气交接、时辰边界、00:00 或 23:00 很近；
- 海外出生但没有城市或时区；
- 历史日期存在时区制度变化；
- 用户主动要求真太阳时；
- 多种计算口径会改变柱位。
