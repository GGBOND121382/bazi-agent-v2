# 产品需求文档（PRD）

## 1. 产品定位

面向希望以传统八字命理框架进行结构化阅读的用户，提供可追溯、可配置、可交互的命盘计算与分析工具。产品将“确定性历法计算”“传统规则证据”“模型归纳解释”分层展示，避免把模型文本伪装成确定事实。

## 2. 核心用户价值

- 用户只需填写公历出生信息，即可获得透明的排盘和起运结果；
- 对节气、换日、真太阳时等临界问题给出明确提示和候选结果；
- 通过命盘卡片、五行结构、大运时间轴和流年日历理解复杂信息；
- 每条关键解读可展开查看命盘事实、规则依据和来源；
- 可保存历史命盘、指定时间范围并导出精美报告。

## 3. 角色

### 普通用户

创建命盘、查看分析、导出报告、管理历史记录。

### 专家审核员（后续）

审核规则、知识块、案例、模型结论和争议口径。

### 系统管理员（后续）

配置模型供应商、数据源、规则版本、成本和审计。

MVP 的普通用户界面与审核/管理界面必须路由和权限隔离。

## 4. MVP 功能

1. 公历出生信息分步录入；
2. 地点、时区和时间口径确认；
3. 临界时间风险提示与候选命盘选择；
4. 确定性四柱、十神、藏干、关系、起运、大运和指定流运；
5. 异步 RAG + 模型分析进度；
6. 命盘总览、五行结构、大运时间轴、流年与流月；
7. 可展开证据的综合报告；
8. 历史记录、删除、重新分析和 PDF 导出；
9. 系统设置中的计算口径只读摘要；
10. 传统文化和非确定性说明。

## 5. 非目标

- 不提供社交社区、付费咨询撮合和直播；
- 不根据命理结论自动做投资、医疗、法律或婚姻决策；
- 不承诺“预测准确率”；
- 不允许用户上传第三方私密人物信息后公开分享；
- MVP 不做复杂多租户企业后台；
- 不把神煞数量作为吉凶评分；
- 不生成无限年/月/日数据，按需计算。

## 6. 成功指标

### 正确性

- 确定性字段 Golden 测试通过率 100%；
- 双历法引擎关键字段冲突均可见；
- 正式报告事实错误零容忍；
- 引用可追溯率 100%。

### 产品质量

- 出生信息录入完成率；
- 报告生成成功率；
- 页面关键操作无阻断错误；
- 桌面与移动核心任务均可完成；
- 视觉回归、无障碍和性能预算达标。

### 模型质量

- 结构化输出成功率；
- 事实支持率；
- 引用支持率；
- 流派一致率；
- 确定性高风险措辞率。

## 7. 关键产品决策

- 默认使用“专业、克制、可追溯”而非“神秘、恐吓、绝对化”的产品语气；
- 五行颜色只作为辅助编码，所有信息同时有文字标签；
- 临界命盘必须由用户确认，系统不静默替用户选择；
- 分析进度展示业务阶段，不显示模型内部思维；
- 结果页首先展示确定性事实，再展示传统规则解释和模型点评；
- 报告内容由结构化块渲染，不能保存为不可编辑的单段 Markdown。
