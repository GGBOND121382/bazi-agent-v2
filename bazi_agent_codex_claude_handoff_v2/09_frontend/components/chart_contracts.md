# 图表组件契约

## FiveElementChart

输入：五个元素的 `explicit`, `hidden`, `total`, `label`。不得在组件内部按天干地支计算。

输出/交互：hover、选中、图例；同时渲染可访问表格。

推荐：水平分组条形图或环形摘要 + 表格，不用雷达图作为唯一表达。

## RelationshipGraph

仅在关系数量较多时使用。节点和边由后端给出；边类型和参与者必须有文字列表。移动端默认列表。

## DayunTimeline

输入：起运点、每步大运起止日期/年龄、当前标记和已验证摘要。桌面双轴，移动列表。不能根据当前日期自行推算所属大运，后端提供 `is_current`。

## MonthActivityChart

只展示“关系活跃度/证据强度”等由后端或验证模型提供的明确指标，不生成吉凶总分。
