# 前端产品交接

本目录定义完整 Web 产品，不是“报告 HTML 模板”。

## 阅读顺序

1. `product_experience.md`
2. `information_architecture.md`
3. `route_map.md`
4. `page_specs/`
5. `design_system/`

7. `frontend_architecture.md`

## 最终体验目标

- 现代、克制、精致的东方视觉；
- 信息密度高但层级清晰；
- 不做传统“大红大金”算命网站；
- 不用通用后台管理模板；
- 先展示确定性事实，再展示规则和模型观点；
- 桌面适合深度阅读，移动端可完成完整流程；
- 所有交互和视觉均有测试标准。
