# 视觉设计系统

## 方向

现代东方、纸墨质感、低饱和、留白和精细线框。不是古风游戏，也不是后台管理模板。

## 色彩

- 纸白为主背景；
- 墨色承载主要文字；
- 玉色为主操作和选中；
- 朱色只用于重点或风险，不大面积铺底；
- 金色用于时间和规则层级点缀；
- 五行颜色只作为辅助，不改变语义状态颜色。

## 字体

- UI 正文使用系统无衬线；
- 四柱和章节标题可适量使用系统宋体 fallback；
- 不打包或分发字体文件；
- 数字和时间使用 tabular numbers。

## 密度

- 普通模式：隐藏规则 ID 和次级藏干详情；
- 专业模式：展示完整字段和证据；
- 不通过缩小字号堆信息，使用 drawer、popover 和分节。
