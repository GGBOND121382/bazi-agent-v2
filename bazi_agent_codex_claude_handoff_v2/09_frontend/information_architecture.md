# 信息架构

```text
公共区
├── 首页
├── 产品说明
└── 分享报告（可选、受 token 控制）

用户区
├── 新建命盘
│   ├── 基本信息
│   ├── 地点与时区
│   ├── 计算口径
│   └── 分析主题
├── 临界命盘确认
├── 分析进度
├── 命盘工作台
│   ├── 总览
│   ├── 五行与结构
│   ├── 大运
│   ├── 流年
│   ├── 流月/流日
│   ├── 神煞
│   └── 综合报告
├── 历史记录
├── 导出记录
└── 设置

管理区（非 MVP 普通用户）
├── 知识来源
├── 规则版本
├── 数据审批
├── 模型与成本
└── 审计
```

## 命盘工作台导航

桌面：左侧章节导航 + 顶部命盘摘要。

移动：顶部紧凑摘要 + 底部主要导航，二级章节使用横向 tabs/目录抽屉。
