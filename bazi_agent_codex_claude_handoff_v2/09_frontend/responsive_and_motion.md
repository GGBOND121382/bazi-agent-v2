# 响应式与动效

## 断点参考

- compact：< 640px；
- medium：640–1023px；
- wide：≥ 1024px；
- reading-wide：≥ 1280px。

不以设备名称决定功能，核心流程在 compact 完整可用。

## 组件变体

- 四柱：桌面四列，移动仍保持四列但压缩附属字段，详情改抽屉；
- 大运：桌面横向双轴，移动纵向列表；
- 报告：桌面固定目录，移动目录抽屉；
- 证据：桌面右侧 drawer，移动 bottom sheet；
- 历史：桌面表格，移动卡片。

## 动效

- 150–240ms；
- 仅用于状态过渡、抽屉、选中和时间轴定位；
- 禁止无限旋转作为唯一进度；
- `prefers-reduced-motion` 下禁用位移动画；
- 不用粒子、星空、烟雾等干扰信息的装饰动画。
